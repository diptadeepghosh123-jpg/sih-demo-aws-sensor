# SkyGuard Assistant - Python/Data-Grounded Chatbot Update

## What changed

- The chatbot backend remains fully Python/FastAPI based.
- `/api/chat` now reads SkyGuard's own stored detection results from SQLite and the sensor registry.
- It explains the actual statuses produced by `anomaly.py`:
  - NORMAL
  - WATCH
  - GLITCH_SUSPECT
  - SENSOR_ANOMALY
  - WEATHER_EVENT
  - DATA_UNAVAILABLE
- It can explain fault types, evidence, severity, confidence, health and recommended next action.
- It supports plain-language questions such as:
  - "What anomalies are present?"
  - "Why is AWS_001 on Watch?"
  - "Explain the glitch on AWS_002 simply"
  - "What happened to AWS_003?"
  - "What should I do about this anomaly?"
  - "What is the prediction for AWS_004?"
- It does not invent readings and does not replace the anomaly engine's decision.
- Prediction answers read the stored prediction metadata generated by `predictor.py`.
